# Mobile Evolution

> **Da Programação Nativa ao Desenvolvimento Multiplataforma**

Uma experiência interativa desenvolvida para a disciplina de **Programação para Dispositivos Móveis**, apresentando a evolução do desenvolvimento mobile de forma moderna, dinâmica e visual.

O projeto substitui uma apresentação tradicional por uma **landing page interativa**, inspirada em grandes conferências de tecnologia como Google I/O, Apple WWDC e Microsoft Build.

## Objetivo

O objetivo deste projeto é apresentar, de forma clara e envolvente, os principais conceitos do desenvolvimento mobile, mostrando a evolução das tecnologias utilizadas na criação de aplicativos e comparando diferentes abordagens utilizadas pelo mercado.

Ao longo da apresentação serão abordados:

* A evolução do desenvolvimento mobile
* Android Studio
* Desenvolvimento Nativo
* React Native
* Comparação entre as tecnologias
* Sistemas Operacionais Mobile
* Panorama do mercado

## Como Executar

Clone este repositório:

```bash
git clone https://github.com/SEU-USUARIO/mobile-evolution.git
```

Entre na pasta do projeto:

```bash
cd mobile-evolution
```

Abra o arquivo `index.html` diretamente no navegador ou utilize a extensão **Live Server** do Visual Studio Code.
