A Linha do Tempo

  • 2008

    Android nasce

    O SDK é lançado e o Android chega ao mercado.

  • 2008–2016

    Java domina o Android

    Linguagem oficial e padrão de mercado por quase uma década.

  • 2013

    Android Studio

    A IDE oficial do Google chega para substituir o Eclipse.

  • 2015

    React Native

    O Facebook populariza o desenvolvimento multiplataforma com JavaScript.

  • 2017

    Kotlin

    Google adota Kotlin como linguagem oficial para Android.

  • 2017

    Flutter

    Google entra na disputa com um framework próprio e performático.

  • Hoje

    Nova Arquitetura do React Native

    Fabric, TurboModules e JSI elevam a performance do multiplataforma em 2026.

Ambiente Oficial de Desenvolvimento

A IDE oficial do Google para Android, construída sobre o IntelliJ IDEA. Reúne tudo o que é preciso para escrever, testar e depurar um app — em um único lugar.

Emulador

Gradle

Compila, empacota e gerencia as dependências do projeto.

SDK

Ferramentas e APIs para acessar os recursos do Android.

Debug

Desenvolvimento Nativo

Java Kotlin Swift

Desenvolvimento nativo é escrever o app diretamente na linguagem e no SDK de cada plataforma — Java/Kotlin para Android, Swift para iOS.

MainActivity.java 
public class MainActivity extends AppCompatActivity {

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        Button button = findViewById(R.id.button);
        button.setOnClickListener(v ->
            Toast.makeText(this, "Nativo!", Toast.LENGTH_SHORT).show()
        );
    }
}

Vantagens

  • Melhor performance e fluidez
  • Acesso total ao hardware e às APIs do sistema
  • UI/UX alinhada aos padrões da plataforma
  • Suporte oficial e atualizações mais rápidas

Desvantagens

  • Código separado para cada plataforma
  • Maior tempo e custo de desenvolvimento
  • Curva de aprendizado por linguagem/SDK
  • Manutenção duplicada

    <View style={styles.container}>

        Você clicou {count} vezes
      </Text>

        title="Clicar"
        onPress={() => setCount(count + 1)}

    </View>
  );
}
